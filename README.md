# Паттерн безопасности «Выдача учётных данных по удостоверению платформы»

Прототип к выпускной квалификационной работе «Паттерн безопасности для защиты учётных данных доступа к сетевым
сервисам в контейнеризованных микросервисных приложениях».

**Автор:** Лукьянов Е. (КА-21-07).
**Руководитель:** доктор технических наук, профессор Корнеев Н. В.
Выпускная квалификационная работа выполнена под руководством д.т.н., профессора Корнеева Н. В.

## Что внутри

| Каталог / файл | Назначение |
|---|---|
| `credshield/agent.py` | Агент доставки: вход по токену платформы, выдача учётных данных, атомарная замена файла, отсрочка при отказах, закрытый отказ |
| `credshield/detector.py`, `adapter.py`, `executor.py`, `responder.py` | Сервис реагирования: разбор журнала аудита, правила выявления отклонений, отзыв аренд роли |
| `credshield/metrics.py` | Метрики в формате Prometheus |
| `credshield/scancheck.py` | Поиск учётных данных в файлах (этап конвейера сборки) |
| `credshield/simulator.py`, `bench.py`, `demoapp.py` | Имитатор API хранилища, нагрузочный замер, демонстрационный микросервис |
| `tests/` | Автоматические тесты (`python -m unittest discover -s tests -t .`) |
| `chart/` | Helm-чарт: PostgreSQL, OpenBao, сервис реагирования, рабочие нагрузки, Prometheus и Grafana |
| `stand/` | Скрипты настройки хранилища, нагрузки, имитации нарушителя и недоступности, подбора порога детектора, результаты испытаний |
| `Dockerfile`, `.gitlab-ci.yml` | Упаковка и конвейер CI/CD |

## Запуск тестов

```bash
python -m unittest discover -s tests -t .
```

## Развёртывание на стенде (kind)

```bash
kind create cluster --name vkr
docker build -t credshield:0.1.0 .
docker save credshield:0.1.0 | docker exec -i vkr-control-plane ctr -n k8s.io images import -
helm install cs chart -n credshield --create-namespace
sh stand/configure.sh
```

Хранилище (OpenBao) запускается в режиме разработки и хранит данные в памяти: после перезапуска пода его нужно
настроить заново командой `sh stand/configure.sh`.
